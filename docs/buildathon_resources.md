## 2. Real-World Test Data Sources

Nothing public gives farmer/buyer/shipment-level records (that's private
commercial data) — the approach is to pull real aggregate numbers from these
sources, then generate synthetic per-record rows distributed to match those
real totals.

| Source                                                                    | Provides                                                                                | Access                                                                                                                                                                               |
| ------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **FAOSTAT**                                                         | Crop production, yield, area harvested by country, 1961–present                        | Free, no registration for small pulls.[fao.org/faostat](https://www.fao.org/faostat/en/)                                                                                              |
| **CARICOM Statistics**                                              | Regional agriculture, forestry, fishing, and intra-Caribbean trade data                 | [statistics.caricom.org/available-datasets](https://statistics.caricom.org/available-datasets/)                                                                                       |
| **CARDI** (Caribbean Agricultural Research & Development Institute) | Caribbean-specific agriculture research/statistics                                      | [cardi.org/links/information-sources/statistics](https://www.cardi.org/links/information-sources/statistics/)                                                                         |
| **UN Comtrade**                                                     | Real import/export volumes by HS code and country pair (e.g. mangoes Jamaica→Barbados) | Free API key, 500 calls/day, 100k records/query.[comtradeplus.un.org](https://comtradeplus.un.org/)                                                                                   |
| **World Bank Open Data**                                            | Country + "Caribbean small states" (code`S3`) economic/agriculture indicators         | Free REST API, no key needed.[data.worldbank.org](https://data.worldbank.org/)                                                                                                        |
| **NOAA HURDAT2 / Historical Hurricane Tracks**                      | Real tropical storm tracks, 1851–present                                               | Free download/API.[nhc.noaa.gov/data](https://www.nhc.noaa.gov/data/), [coast.noaa.gov historical tracks tool](https://coast.noaa.gov/states/stories/historical-hurricane-tracks.html) |
| **CIMH** (Caribbean Institute for Meteorology & Hydrology)          | The actual regional met agency — potential live weather feed                           | Check data-access terms directly.[cimh.edu.bb](https://www.cimh.edu.bb/)                                                                                                              |


### Suggested approach

Pull real aggregate tonnage/trade numbers from FAOSTAT/CARICOM/Comtrade for
the crops and islands this app models, then generate synthetic
farmer/buyer/shipment rows proportioned to those real totals — demo data
grounded in reality without needing (nonexistent) public farmer-level
records.
